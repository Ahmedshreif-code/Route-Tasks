## Download a Single Task

To get one task instead of the whole repository, use [download-directory.github.io](https://download-directory.github.io/):

1. Open this repository on GitHub and go into the task folder you want.
2. Copy the URL of that folder.
3. Paste it into [download-directory.github.io](https://download-directory.github.io/) and press **Enter**.
4. The folder downloads as a ZIP file.

To get everything, clone the repository:

```bash
git clone https://github.com/Ahmedshreif-code/Route-Tasks.git
```
